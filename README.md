# Python Student Record Manager

## Project Overview

The Python Student Record Manager is a console-based application
developed to practise fundamental Python programming concepts.

The application allows users to create, view, search, update and
delete student records.

## Problem Being Addressed

Managing student information manually can become difficult as the
number of records increases.

This project provides a simple digital system for storing and
managing basic student information.

## Technologies Used

- Python 3
- JSON
- Git
- GitHub

## Features

The application allows users to:

- Add a new student
- View all students
- Search for a student using a student number
- Update an existing student record
- Delete a student record
- Save records to a JSON file
- Load saved records when the application starts
- Handle invalid user input

## Student Information Stored

Each student record contains:

- Student number
- Name
- Course
- Year of study
